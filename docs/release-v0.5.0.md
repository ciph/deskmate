# YUME v0.5.0（Windows）

本次提供 Windows x64 安装包及 Tauri 自动更新签名，新增内置桌宠“百变小著”。macOS 安装包稍后补发；在补发前，已有 macOS 程序可继续使用，检查更新可能提示暂无适用安装包。

## 更新内容

- 新增内置角色“百变小著”：设置 → 桌宠 → 角色 → 百变小著。原来三个小著角色和默认选择不变。
- 同一个小著可在团子、枕头、年糕、幽灵四种形态间连续变形，各有自己的待机、移动和被拎起的动作。
- 单击戳一下，拖动拎起、松手软软落下，双击或 Enter 打开聊天；右键切换形态、散步、睡觉/叫醒和自动活动；聚焦后空格戳一下、1–4 切换形态。
- 聊天显示或 AI 工作时暂停自主活动，生活动作不代表真实任务结果。
- 像素墨镜在非整数系统缩放下对齐屏幕像素；拎住不动再松手时垂直落下，甩出时保留惯性。

## 已有验证

- 基于 0.4.24 合并后的源码：类型检查、前端 182/182 文件、Rust 978 项、生产构建及 GitHub Actions Windows/macOS 源码检查通过。版本号提交后未改产品逻辑。
- 独立 debug 预览在同一台 Windows 机器（125% 缩放、三台显示器、60 Hz）上用真实系统鼠标键盘实测：空闲与散步约 59–60 次画面更新/秒、透明区域穿透、戳碰、拖放、跨屏落地、右键菜单、键盘切换形态、聊天时暂停移动。这是 debug 预览的结果，不是本安装包的安装后实测，也不代表其他机器。

## 已知问题

- 双击打开聊天偶尔可能没有响应，原因尚未查明，后续多次重测未复现；可再次双击，或使用 Enter、右键菜单。
- 默认 0.5 倍大小、125% 缩放时，墨镜为对齐像素比设计尺寸约小 10%。

## 未验范围与保留边界

- 本版本最终安装包的真实安装、从旧版本的 GUI 自动更新尚未实测。
- 百变小著在 150%/175% 缩放、120/144 Hz、DPI 不同的显示器间拖动、睡着/叫醒的完整原生周期、AI 工作时的状态标记，以及 macOS 实机上均未验证。
- Mac 需在维护者 Mac 上签名、公证后补发；Actions 中的未签名候选不是公开下载。
- 本次不增加数据库迁移，历史 schema 3、记忆 schema 4 保持不变。Tauri 更新签名不等同于 Windows Authenticode，Windows 可能仍提示未知发布者。
