## 本轮真正改了什么

- Stop 的本地请求标识与取消事件配对：本窗口正在取消的同一请求，不再显示“出错了: Aborted”。未主动取消的 abort、其他服务错误仍显示。回归先失败后通过，覆盖三种取消名称、普通错误与旧请求边界。
- 历史工作日志回执明确传入所选项目目录，并按每次会话/目录作用域拒绝迟到查询。即使离开后重新访问相同会话，也不会接收旧查询的结果。既有拒绝回执不能被空查询覆盖的修复保留。
- 补齐被全局 `*.log` 忽略的 201 份既有精选日志（约 1.4 MB）；扫描已知临时令牌与常见凭据模式无命中，276 个旧便携报告链接均可由 Git 中的文件解析。历史证据字节及原失败保持，未把原始私有桌面截图批量入库。

本轮读取模型验证后的历史时出现一次初始化中的普通读取失败，待项目就绪后重试成功。普通读取 5 秒预算与冷项目独立 120 秒准备预算不同；首次插件初始化仍可能耗时数十秒。
