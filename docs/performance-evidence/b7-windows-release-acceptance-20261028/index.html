- 停止后的隔离数据库构造最近漏周；重启实际进入运行，真实暂停后取消。请求发出并超过 60 秒服务延迟后仍取消且未归档；没有单独证明响应已被客户端接收。重启保留历史与浅色主题；固定窗口浅深色表面已观察。
- 十次普通重复启动退出 0，主进程和侧车身份保持；这不是活跃工具进行中二次启动的验收。
