# YUME v0.4.23（Windows）

本次提供 Windows x64 安装包及 Tauri 自动更新签名，交付长历史交互与工作日志回执读取优化。macOS 本次不提供新安装包；已有 macOS 程序可继续使用，检查更新可能提示暂无适用安装包。

## 更新内容

- 聊天正文与对话导航按可见范围渲染，支持直接跳到尚未挂载的历史消息；保留代码横向位置、焦点、播放中的媒体及文本选择，输入框和 Stop 持续可用。
- Markdown 全文解析移入本地 Worker，合并过期流式格式请求；正文尾部即时显示，保留 CommonMark/GFM、复制、表格和原有链接/HTML 安全策略。
- 工作日志回执复用正文快照，按最多 50 个请求 ID 合批精确读取；普通 idle 不再额外读取全会话，旧于最近 100 条的任务仍能正确恢复。
- 完善先订阅再加载、断线恢复和视图代次保护；修复同会话重开漏接后续事件、真实点击 Stop 后焦点丢失、Worker 浏览器依赖错误和虚拟列表占位高度被 CSS 覆盖的问题。

## 已有验证

- 本次复用已完成的长历史验收：前端 1,386 通过、0 失败、8 项 Mac 专用跳过；三套类型检查、相关 Rust 精确读取 2 项和快照投影 1 项、隔离 Windows release 构建通过。仅失败及受影响项定向复测，不重复本机已通过且未受影响的套件；发布 tag 工作流仍执行自身门禁。
- 1000 条历史、50 Hz、500 块合成流式下，10k/50k 字符的输入 p95 为 32.9/33.2 ms，滚动 p95 为 38.4/34.8 ms；各 30 对有效流式样本，全部满足预先约定的 ≤50 ms 和相对基线回退 ≤20%。正文原文 SHA 校验一致。
- 一万条历史的首、中、尾导航分别挂载 12/20/11 条正文；窗口宽度 900→650 物理 px 后阅读锚点偏差 0.4 CSS px。真实 Stop/草稿/续聊、复制、表格滚动、选择、媒体播放与移除、旧任务回执和目录切换已验证；SSE 恢复及 Agent/只读/legacy 对应路径有原生或自动回归证据。
- 这些数据来自同机 Windows、125% 缩放、隔离合成数据候选，不是最终安装包安装后的全场景实测；输入 p50 并非全部改善，不承诺整机提速或省电百分比。
- 安装资产公开前核验版本、内容、图标、SHA-256、Tauri 更新签名和更新清单；公开后匿名回读资产。详细过程、失败记录及复测范围见[长历史交付报告](https://github.com/ciph/deskmate/blob/v0.4.23/docs/performance-evidence/long-history-closeout-20261029/README.md)。报告中的 0.4.22 是该轮验收时的候选版本，发布准备仅同步版本元数据和说明。

## 未验范围与保留边界

- 本版本最终安装包的真实安装、跨版本 GUI 自动更新尚未实测；构建、签名及隔离原生验收不能替代安装/升级验收。
- Mac 最终实机 GUI/恢复、签名安装与更新，混合 DPI、高刷新率、GPU 驻留与功耗前后对照，以及真实付费模型的工作日志/记忆语义仍未完成验证。Mac CI 未签名候选不作为公开安装下载。
- 磁盘实际耗尽、任意进程中断迁移、完整修复 UI、所有尺寸/语言/动作极值及长期零泄漏未穷尽验证。
- 首次正文仍完整读取，Worker 内 Markdown 仍执行完整语义解析；R06 全快照比较、D20 全库读取和 M19c 硬删除扫描的剩余成本未在本次优化。首次项目插件初始化仍可能耗时数十秒。
- 本次不增加数据库迁移，历史 schema 3、记忆 schema 4 保持不变。旧版本不能被视作数据库无损降级工具；升级前备份仍应保留。
- 保留原版角色模型与默认 60 fps。Tauri 更新签名不等同于 Windows Authenticode，Windows 可能仍提示未知发布者。
