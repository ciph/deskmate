# YUME v0.4.21（Windows）

本次发布 Windows x64 安装包及自动更新签名。macOS 本次不提供新安装包；现有 macOS 程序可继续使用，更新检查可能提示该版本暂无适用安装包。

## 更新内容

- 改善长会话流式回复：首段立即显示，后续正文合批更新，减少历史消息的重复渲染；保留代码、表格、工具状态及固定角色回复的原有行为。
- 修复历史多段正文恢复可能重复、迟到停止响应影响新会话的问题。明确发送失败时撤回未提交的气泡，保留草稿并显示重试提示；结果不明时避免重复提交。
- 减少任务后台的完整历史读取与重复落盘。复用引擎事件刷新变化消息，保留断线、终态和低频全量核对；归档准备退出控制锁，提交前仍校验会话、所有权及删除状态。
- 改善工作记录删除：集中处理来源与派生快照，减少重复扫描和无关写入；补齐深层独立快照清理，以及被删除报告被旧生成任务重新写回的问题。
- 减少大附件上传时的 JSON 编码开销，完善切换、取消及迟到响应清理；修复 PDF 处理与记忆导出的相关可靠性问题。
- 按需加载工作台和 3D 宠物代码，隐藏时停止相应渲染与光标轮询；改善高刷新率屏幕上的帧率控制，缓存已验证的模型边界计算。
- 调整后台任务唤醒、事件去重和引擎重启退避，减少空闲轮询及重复工作；强化启动并发、日志桥和状态持久化边界。

## 验证与说明

- 发布前执行类型检查、完整前端回归、Rust library 测试及前端/Windows 编译；长会话、停止、重试、切换、卸载另以真实产品代码和隔离数据验证。
- 性能数字来自明确负载的合成或浏览器场景，不代表整机提速或耗电保证。原版角色模型及默认 60 fps 保留，本次未采用低分辨率候选资源或默认 30 fps。
- 安装包及自动更新签名在公开前下载回读，核验版本、内容与密码学签名。Tauri 更新签名不等同于 Windows Authenticode，系统可能仍显示未知发布者。
- 完整原生安装/跨版本自动更新、WebView2 真实模型与 SSE、拖拽/媒体、多显示器/DPI、高刷新率、真实内存/GPU/功耗及 macOS 仍有待验项；构建和隔离回归不代替这些场景。
