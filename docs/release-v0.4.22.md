# YUME v0.4.22（Windows）

本次提供 Windows x64 安装包及 Tauri 自动更新签名，集中交付 B6/B7 历史、记忆与 Windows 稳定性修复。macOS 本次不提供新安装包；已有 macOS 程序可继续使用，检查更新可能提示暂无适用安装包。

## 更新内容

- 修复 Windows 原生窗口绘制重入引起的 Tao 崩溃；修复审批 SSE 连接等待超时后的恢复，避免审批控制被卡住。
- 修复首次加载大量历史消息时 Stop 消失、输入框被卸载及提交后焦点丢失；主动停止当前回复不再误显示 Aborted 错误，其他真实错误仍会提示。
- 修复冷启动历史发现的初始化等待与事件竞态；完善原生流式文本增量、历史附件标签和导航预览。
- 修复工作日志旧拒绝回执被空查询覆盖、历史重开缺少回执，以及跨项目目录或切换会话时迟到回执串入的问题。
- 历史目录新增 revision 失效、按记录事务更新和索引分页，减少重复扫描；记忆库增加到期索引、有界维护及稳定的全文检索标识。
- 完善 PDF 成功、失败和取消时的资源释放，以及附件选择、拖放、媒体播放、日志编辑/导出/删除与失败恢复链路。

## 已有验证

- 发布准备复用同一产品源码的完整本机结果：前端 1373 通过、Rust 974 通过，均 0 失败；8 项 skip、24 项 ignored 不计入通过。此次不重复执行本机整套测试，发布工作流仍执行自身门禁。
- 隔离 Windows 原生验收覆盖：1000 条历史下的 10k/50k 流式正文完整校验、Stop/焦点/续聊；活跃工具期间 10 次二次启动；归档故障期间审批与取消；32 次 PDF 循环及 worker 清理；三种宠物隐藏恢复、同 DPI 多屏与十分钟空闲观察。
- 已有 release 物理验收覆盖原生附件选择器、文件拖放、MP4/MP3/WAV 与文件夹、工作日志编辑/冲突/导出/删除和失败重试。旧库受控迁移失败回滚、重开及中文记忆导出已有证据。
- 安装包公开前核验版本、打包内容、SHA-256、Tauri 更新签名与更新清单，公开后回读下载资产。完整证据见 [B7 审计报告](https://github.com/ciph/deskmate/blob/v0.4.22/docs/performance-evidence/b7-windows-closeout-20261028/README.md) 和 [20 项审计矩阵](https://github.com/ciph/deskmate/blob/v0.4.22/docs/performance-evidence/b7-windows-closeout-20261028/audit-matrix.json)。

## 未验范围与使用说明

- 本版本最终安装包的真实安装、跨版本 GUI 自动更新尚未实测；构建与隔离原生验收不能替代安装/升级验收。
- Mac 最终实机 GUI/恢复、混合 DPI、高刷新率、GPU 驻留与功耗的生产前后对照、真实付费模型的工作日志语义仍未完成验证。
- 磁盘实际耗尽、任意进程中断迁移、完整修复 UI、原生全部动作极值及长期零泄漏未作穷尽验证；已有受控故障回归不代表所有故障场景均通过。
- 历史目录 schema 升至 3，记忆库 schema 升至 4。不能把回退程序当作数据库无损降级；请保留升级前备份，避免旧程序直接写入新库。
- 首次项目插件初始化仍可能耗时数十秒；长历史仍全挂载，活动 Markdown 与日志回执恢复仍存在全文读取成本。本次不承诺整机提速或省电百分比。
- 保留原版角色模型和默认 60 fps，未采用压缩候选或默认 30 fps。Tauri 更新签名不等同于 Windows Authenticode，Windows 可能仍提示未知发布者。
