# 运行生命周期：当前契约

核对日期：2026-10-22。本文记录 B3 已实现的启动、加载与恢复规则；执行结果和原生待验项统一见[当前验收与待办](verification-backlog.md)。构建输入继续以[工作台构建](workbench-build.md)为准。

## 工作台首次创建与会话交接

宿主启动不创建工作台 WebView。首次显示或打开指定会话时，宿主串行检查已有窗口并创建一次；创建失败保留重试能力。首次创建在后台阻塞任务中执行，避免 Windows UI 线程同步创建 WebView。显示成功不提前认领会话输入；创建失败或窗口未实际显示时不授予输入所有权。

会话交接先保存完整目录和会话 ID；首次页面尚在加载时，后来的交接替换待处理目标。页面安装事件监听、挂载实际路由后串行领取最新目标，通知只负责唤醒，不依赖页面加载前发出的事件。实际路由确定后才认领输入；隐藏或关闭释放所有权，原有六秒租约仍有效。关闭继续隐藏并保留 WebView，重开保留页面状态，不反复销毁重建。完整会话身份和历史规则见[统一历史契约](migrations/opencode-native/unified-history-contract.md)。

## 3D 渲染按需加载

桌宠设置加载完成且选中 3D 角色后，才动态导入 GLB 视图及 Three/VRM 渲染依赖。冷启动选中 GIF 或 rig2d 时不走该动态导入；设置尚未返回时也不预加载默认 3D 角色。模块已加载后可在同一页面复用。

3D 模块和角色资源加载期间显示加载状态，失败提供重试及切换角色入口。重试重新挂载该角色的渲染实例；角色、资源修订或组件生命周期已变化时，旧加载结果不能创建过期渲染实例或覆盖当前就绪状态。已有动作、情绪和睡眠语义继续由原渲染器与活动状态管理。

已发出的动态 import 不承诺取消下载或解析；切回 2D 的约束是忽略晚到结果并停止使用旧实例，不代表浏览器模块缓存立即回收。资源加载与交互回归不等于原生 GPU、WebView 数量、内存或功耗已经实测下降。

## 受管引擎恢复

首次启动之外，连续失败最多触发八次自动尝试，等待依次为 1、2、4、8、16、30、30、30 秒。重复失败通知不重复消耗同一次尝试或推迟其期限。成功创建进程不会清空预算；连续健康观测达到 30 秒才重置。启动未就绪或之后持续失健康达到 15 秒会进入失败处理；稳定后 HTTP 健康检查间隔为 30 秒，因此新健康故障可能先等待下一次观测，再开始这 15 秒窗口。进程退出仍按约一秒间隔检查。

预算耗尽后停止自动拉起，显式设置重试可清空预算并立即再试。Agent 的自动隔离进入同一恢复策略，不冒充手动重试清空预算。HTTP 检查和退避等待不持有恢复锁；退出或恢复通知可唤醒等待。进程代次用于隔离迟到结果，旧进程的健康回复不能确认新进程已就绪；仅处理宿主持有的子进程，不凭陌生 PID 判定或终止进程。

## 有界诊断日志

受管引擎 stdout/stderr 和宿主固定失败诊断共用日志写入器，跨引擎重启追加和轮转。`sidecar.log` 加三个备份，每个最多 64 KiB，总计最多 256 KiB；保留启动错误类别/系统码、退出码、健康超时和预算耗尽等诊断，不无限增长。轮转可能淘汰较早故障，日志不是永久审计记录。

写盘前按完整行处理：隐藏已知的引擎密码、Basic 鉴权头及配置/认证秘密；出现敏感字段名的行保守隐藏；超过 8 KiB 的整行丢弃，避免截断后遗留凭据片段。未知、额外编码或任意拆分的秘密不能获得通用检测保证，敏感关键词也可能隐藏本可保留的普通诊断。磁盘写入失败仍排空子进程输出管道，避免日志故障阻塞引擎。

Windows/macOS 原生窗口首次打开、隐藏重开、睡眠恢复、真实坏配置进程及整机资源测量仍需对应实机验收；本契约不把单元测试或浏览器测试升级为这些场景通过。
