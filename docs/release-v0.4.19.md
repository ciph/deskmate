# YUME v0.4.19（Windows）

本次发布 Windows x64 安装包及自动更新签名。macOS 本次不提供安装包，继续使用已有正式版本。

## 更新内容

- 聊天消息显示双方的圆角方形头像；可在「设置 → 通用 → 我的头像」更换或恢复个人头像。
- 历史回复按当时的角色显示头像，包括一段会话中切换过角色的情况；无法可靠识别的旧记录使用中性头像。
- 加快历史记录加载：先显示本地目录、后台同步，单条查询使用索引，只写入变化记录；普通聊天发送不再重复读取完整正文。
- 自动清理无人使用的空会话，保留当前草稿、任务、文件/工具消息及状态不明的记录；新建或刚活动的会话保留 30 秒保护期。
- 减小 Windows 安装包：桌面控制组件改为首次启用时按需下载并校验，聊天、工作台和宠物仍随安装包提供。
- 简化 AI 配置入口，移除已退役的外部部署流程；原有旧配置恢复能力保留。
- 包含此前尚未正式发布的菜单主题修复，以及任务恢复、记忆库并发和迁移可靠性改进。

## 验证与说明

- 通过类型检查、前端隔离回归、Rust library 测试与前端构建；历史查询、空会话删除边界、头像及继续发送已完成隔离回归。
- Windows 安装包和自动更新签名在发布构建后回读验证。Tauri 更新签名用于校验下载完整性，不等同于 Windows Authenticode 证书签名；系统可能仍显示未知发布者。
- 完整原生拖拽、物理多显示器、真实模型与跨版本自动更新交互仍以当前验收待办为准，单元测试和构建不代替这些场景。
