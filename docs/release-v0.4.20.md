# YUME v0.4.20

本次为 macOS Apple Silicon 提供安装包与自动更新包，同时生成相同版本的 Windows x64 安装包。应用功能沿用 0.4.19；已公开的 0.4.19 Windows 资产保持不变。

## 更新内容

- macOS 同步聊天双方头像、个人头像设置、历史加载优化与空会话清理等 0.4.19 改进。
- macOS 包内提供音频转换组件所需的 TagLib，避免依赖用户安装 Homebrew 动态库。
- Windows 保留 0.4.19 的按需桌面控制组件和简化后的 AI 配置入口。

## 验证与说明

- macOS 正式资产须通过 Developer ID 签名、Apple 公证、包内依赖校验和 Tauri 自动更新签名后公开。
- 本机类型检查、154 个前端测试文件（1123 个用例）及前端构建通过；0.4.20 Rust library 测试 724 个通过、15 个按既有条件忽略、0 个失败。
- 原生界面、隔离跨版本更新和最终资产的实际结果记录在本次发布证据中；构建成功不代替运行验收。
- 物理多显示器、完整原生拖拽和真实模型等未覆盖场景继续以[当前验收待办](verification-backlog.md)为准。
